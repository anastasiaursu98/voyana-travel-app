# Voyana

Voyana is a travel and vacation booking platform focused on premium, accessible trip planning experiences.

The project is split into two sibling applications:

- `voyana-frontend`: React, Vite, TypeScript, Tailwind CSS, MUI, and the travel booking interface.
- `voyana-backend`: Express, MongoDB, and the authentication API surface.

The current product surface implements the travel booking interface and shared application shell.
