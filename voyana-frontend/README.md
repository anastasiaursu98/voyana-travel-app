# Voyana Frontend

React + Vite + TypeScript frontend for the Voyana travel booking experience.

## Stack

- React 19
- Vite
- TypeScript strict mode
- Tailwind CSS
- Material UI
- React Router
- Axios
- React Hook Form + Zod

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env` when the backend API URL is known.
